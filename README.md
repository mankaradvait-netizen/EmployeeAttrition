# EmployeeAttrition

End-to-end Employee Attrition Prediction project using Python, Machine Learning, and HR Analytics. Includes EDA, preprocessing, feature engineering, Logistic Regression, Random Forest, Gradient Boosting, GridSearchCV, model evaluation, and business-focused HR recommendations.
